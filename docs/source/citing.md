# Citing

This package is derived from ASH. If it is useful in your research, please cite:

> [ASH: a Multi-scale, Multi-theory Modeling program](https://onlinelibrary.wiley.com/doi/10.1002/jcc.70359),
> R. Bjornsson, *J. Comput. Chem.* **2026**, 47, e70359.

```bibtex
@article{bjornsson2026ash,
  author  = {Bjornsson, Ragnar},
  title   = {{ASH}: a Multi-scale, Multi-theory Modeling program},
  journal = {Journal of Computational Chemistry},
  volume  = {47},
  pages   = {e70359},
  year    = {2026},
  doi     = {10.1002/jcc.70359},
}
```

Please also cite the programs a calculation actually used —
[ORCA](https://www.faccts.de/orca/), [OpenMM](https://openmm.org),
[geomeTRIC](https://github.com/leeping/geomeTRIC), [PLUMED](https://www.plumed.org) — each of
which asks for its own citation.
